# DailyLumen 独立部署（无 WorkBuddy）

> 适用：只用系统 Python + DeepSeek，不依赖 WorkBuddy 宿主。  
> 版本锚点：**v1.57.0**｜契约见 [`LLM能力拆分草案.md`](LLM能力拆分草案.md)｜日常流程见 skill `daily-review-intake`。

## 1. 安装

```bash
git clone git@github.com:deTian0/DailyLumen.git
cd DailyLumen
python -m pip install -e .          # pydantic / pydantic-settings
python -m review_tool version       # 应打印当前版本
python -m unittest discover -s tests -t .
```

要求：**Python ≥ 3.10**。运行时仅上述两依赖；⛔ 不另装 openai / DeepSeek SDK。

## 2. 本机目录与 `local/.env`

```text
local/
├── .env                 # 凭据与 mode（gitignore）
├── reviews.db           # 可从 review_tool/reviews.example.db 复制
└── 每日复盘/
    ├── 复盘/YYYY-MM/    # 定稿复盘 md（ingest 扫描）
    ├── 收件箱/          # 截图 / 简报（不参与 ingest）
    │   └── 已处理/YYYY-MM-DD/   # llm-day / inbox-archive 归档（可选）
    ├── 草稿箱/          # AI / 候选未定稿（不参与 ingest）
    └── 历史源复盘/      # 旧格式归档（不参与 ingest）
```

复制 `.env.example` → `local/.env`，至少配置：

```env
# 日常建议 workbuddy；独立跑 DeepSeek 日流程时临时改 deepseek
DAILYLUMEN_LLM_MODE=deepseek
DEEPSEEK_API_KEY=sk-...
# 可选：DEEPSEEK_BASE_URL / DEEPSEEK_MODEL（文本默认 deepseek-chat；
# Vision 固定走 deepseek-flash，不受 MODEL 覆盖）
```

测完独立跑后，把 `DAILYLUMEN_LLM_MODE` **改回 `workbuddy`** 作日常宿主（可保留 Key）。  
⛔ 密钥永不进 git / 日志 / 报告。

## 3. 真实截图投放路径

把薄荷饮食 / 睡眠 / 屏幕等 **jpg/png** 放到：

```text
local/每日复盘/收件箱/
```

示例文件名（本机历史素材，**勿 commit**）：`截图-YYYY-MM-DD-薄荷饮食….jpg`。  
无体脂秤时**不要**投假体脂图、也不要在数据块伪造 `体脂率`。  
仓库 CI 用合成 PNG fixture 证明流程；真实隐私图只在本机 `local/`。

## 4. 闭环四步：write → finalize → ingest → archive

```bash
# ① 临时切 deepseek（测完改回 workbuddy）
# local/.env: DAILYLUMEN_LLM_MODE=deepseek

# ② write（默认 dry-run；确认后 --write 只写 md，戳 pending）
python -m review_tool llm-day \
  --image local/每日复盘/收件箱/截图-….jpg \
  --image local/每日复盘/收件箱/另一张.jpg \
  --date YYYY-MM-DD --diff
python -m review_tool llm-day ... --date YYYY-MM-DD --write [--review]
# 可选：写盘成功后立刻归档本次图
#   ... --write --archive-inbox

# ③ 人审定稿（本地 md 变换，不依赖 DeepSeek / mode）
python -m review_tool llm-finalize YYYY-MM-DD          # dry-run
python -m review_tool llm-finalize YYYY-MM-DD --write  # 清 pending；七-A→七-B

# ④ ingest（先 md 再入库；含 pending 时默认仍会跳过）
python -m review_tool ingest local/每日复盘/复盘/YYYY-MM/YYYY-MM-DD.md

# ⑤ 归档（若 ② 未加 --archive-inbox）
python -m review_tool inbox-archive --date YYYY-MM-DD \
  --file local/每日复盘/收件箱/截图-….jpg --write
# → 移到 收件箱/已处理/YYYY-MM-DD/（可还原；优先移动勿删）

python -m review_tool doctor
# 可选分数收口：python -m review_tool finalize --date YYYY-MM-DD --apply
```

- 多图：**后图非空覆盖先图**；冲突进结果 / `local/llm_last_run.json`。  
- **体脂可选**：图上无体脂秤读数则省略，禁止估算。  
- `llm-finalize` ≠ 分数收口命令 `finalize`（后者是 M38 入库收尾）。  
- 红线：**先 md 再 ingest**；禁止只进库；四维分数归库（勿手改「六、四维评分」）。

分拆命令：`llm-vision`（数据块）/ `llm-review`（「七、AI」七-A 草稿）。

## 5. 无 DeepSeek 时

`DAILYLUMEN_LLM_MODE=workbuddy`（或不配）：手填 / 其它编辑器写 md，只跑 L0 CLI  
（`ingest` / `doctor` / `ai-context` / `week`…）。系统完整可用。  
定稿仍可用：`python -m review_tool llm-finalize <日> --write`（纯本地）。
