**读图要点**

- **自动化采集通道两条**：ClickUp（素材 + `habit_logs` 快照）与练练（训练 / 体征读入 → 先落 md）。截图 / Vision 仍是输入通道。
- **md 是源、库是派生**：删库可从 md 100% 重建（安全网；新增能力必须守住）。
- **评分只由 `config.py` 规则 + 数据块决定**；ClickUp / 练练写回拿不到四维分一票。
- **Web 看板** = 同源 UI；写操作走 `plan → confirm`（须 `--enable-write` + `DAILYLUMEN_WEB_KEY`）。
