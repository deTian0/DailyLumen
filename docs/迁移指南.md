# DailyLumen 迁移指南（换机 / 重装）

> 目标：把本系统完整搬到另一台电脑继续跑。
> **M45 起**：个人日记、截图、库、凭据归一到本机 **`local/`**（公开 git **不再**含复盘全集）。
> 换机 ≈ `clone` + 恢复 `local/`（复盘 md / `.env` / 可选 db）+ 几条命令。

---

## 一、什么在 git、什么不在

### 已入库（`git clone` 即得）

| 内容 | 路径 |
| --- | --- |
| 全部代码 + 测试 + CI | `review_tool/`、`tests/`、`.github/workflows/ci.yml` |
| CI 合成语料（非个人日记） | `tests/fixtures/corpus/` |
| 打包 / lint 配置 | `pyproject.toml`、`requirements.txt`、`.gitattributes` |
| 空白复盘模板 | `每日复盘模板.md`（无个人日记） |
| `local/` 占位 | `local/.gitkeep`、`local/README.md` |
| 空库模板 | `review_tool/reviews.example.db` |
| 凭据键名模板 | 根 `.env.example`（**无真值**；复制为 `local/.env`） |
| 文档 + 项目级 skill | `docs/`、`.workbuddy/skills/**` |

### 不在 git（本机 `local/` · 迁移决策）

| 路径 | 内容 | 迁移动作 |
| --- | --- | --- |
| `local/每日复盘/` | 复盘 md + 收件箱截图/素材 + 历史源 | **必须搬**（或从私有备份恢复）——「删库重建」依赖此树 |
| `local/.env` | API Key 等凭据 | **必须配** —— 从源机拷贝，或按 `.env.example` 新建填写 |
| `local/reviews.db` | 个人 SQLite | **可选搬**；不带可从 `local/每日复盘/复盘/` `ingest` 重建 |
| `local/exports/` | 导出产物 | **不搬，重建** —— `python -m review_tool export` |
| `local/backup/` | 迁移/schema 备份 | 可选；真出问题优先从 md 重建 |
| `.workbuddy/memory/` 等 | 本机坑与日志 | **不迁移**（skills 已在 git） |

> ⛔ `local/**`（除占位）已被 `.gitignore` 排除；**不要**把 `local/.env` / 日记 / db 加入 commit。

## 二、环境依赖（新机只需要这些）

- **Python ≥ 3.10**（`pyproject.toml` 声明；本机验证 3.13）
- **运行时依赖（M46）**：`pydantic` + `pydantic-settings` —— `pip install -e .` 或
  `pip install -r requirements.txt`（⛔ 不另装 `python-dotenv` 为项目直接依赖）
- `git`（仓库从 GitHub 克隆需 SSH）
- 可选：`ruff`

## 三、新机落地步骤

```bash
git clone git@github.com:deTian0/DailyLumen.git "每日复盘计划"
cd 每日复盘计划

# 1) 恢复本机数据父目录
mkdir -p local
# 从源机 / 私有备份拷入：
#   local/每日复盘/   （整树）
#   local/.env        （或：cp .env.example local/.env 后填写 Key）
#   local/reviews.db  （可选）

# 2) 安装运行时依赖（pydantic*）
pip install -e .

# 3) 无库时从 md 重建（首次会按 schema 建库到 local/reviews.db）
python -m review_tool ingest

# 4) 体检
python -m review_tool doctor

# 4) 全量测试
python -m unittest discover -s tests -t .
```

**手工事项**：

1. **`local/每日复盘/`** —— 没有它就无法从本机重建个人库（公开 clone 只有合成 fixture）。
2. **`local/.env`** —— 练练 / ClickUp 等凭据；缺了则相关 CLI 静默无数据或读不到 Key。
3. **`local/reviews.db`** —— 可选；搬了建议再跑一次 `ingest` 核对对账。

## 五、换机后验证清单

- [ ] `python -m review_tool doctor` → 退出码 `0`，结论「数据健康」
- [ ] `doctor` 文件 ↔ 库对账干净
- [ ] `python -m review_tool sync-docs --check` → `0 篇待同步`
- [ ] `python -m review_tool recompute-scores` → `0 处差异`
- [ ] `python -m unittest discover -s tests -t .` 全绿
- [ ] `local/每日复盘/` 与 `local/.env` 在位；`git check-ignore -v local/每日复盘/复盘/...` 命中 ignore
- [ ] `git ls-files local` 仅 `.gitkeep` + `README.md`
- [ ] `.workbuddy/skills/` 下项目级 skill 齐全
